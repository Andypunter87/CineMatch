CineMatch Chat Data Persistence & Recommendation Enhancement

Chat Data Flow Overview

User Chat Session → Firestore Storage → Recommendation Enhancement
  1. User interacts with CineMatch chat interface
  2. Custom vibe preferences and personalized moods are captured
  3. Data is saved to Firestore collections under users/{userId}/
  4. Recommendation engine retrieves and analyzes user patterns
  5. Enhanced recommendations based on historical preferences

Firestore Data Structure

users/{userId}/ ├── chat_sessions/{sessionId} │ ├── id: string │ ├── userId: number │ ├── messages: Array<ChatMessage> │ ├── preferences: RecommendationRequest │ ├── customVibes: string[] │ ├── personalizedMoods: string[] │ ├── completed: boolean │ └── createdAt/updatedAt: timestamps │ ├── vibe_preferences/{vibeId} │ ├── text: string │ ├── frequency: number │ ├── lastUsed: timestamp │ └── source: 'user_custom' | 'ai_generated' | 'predefined' │ ├── preferences/settings │ ├── country: string │ ├── streamingServices: string[] │ └── lastUpdated: timestamp │ └── ratings/ ├── onboarding/films/{filmId} └── recommendations/films/{filmId}

Chat Persistence Implementation

// useChatPersistence hook functionality: ✓ saveChatSession(sessionData) - Saves complete conversation history - Stores user preferences and custom vibes - Tracks AI-generated personalized moods ✓ saveVibePreference(vibeText, source) - Records custom mood preferences - Tracks usage frequency for popularity - Differentiates user vs AI-generated vibes ✓ savePersonalizedMoods(moods) - Stores AI-generated mood options - Links to user context and preferences - Available for future recommendation sessions

How User Data Improves Recommendations

  • Vibe Frequency Analysis: Most-used custom vibes are prioritized in future mood matching
  • Conversation Context: Chat history reveals user language patterns and preferences
  • Personalized Mood Evolution: AI learns from user's custom vibe selections to generate better options
  • Pattern Recognition: Identifies user preferences for custom vs AI-generated content
  • Cross-Session Learning: Previous chat sessions inform future recommendation strategies

Recommendation Enhancement Strategy

Multi-Source Data Integration:
  1. Merge user ratings from onboarding and recommendation feedback (weighted scoring)
  2. Analyze vibe preferences by frequency and recency for mood matching priority
  3. Process chat context for conversational personalization patterns
  4. Apply user constraints (streaming services, country, runtime preferences)
  5. Learn language patterns from custom vibe descriptions for future AI generation

Data-Driven Personalization Examples

Example User Pattern Analysis: User has 3 chat sessions with custom vibes: - "Something that makes me feel empowered" (frequency: 4) - "A film that sparks my creativity" (frequency: 2) - "Stories of underdogs winning" (frequency: 3) AI Learning Results: → Recognizes preference for empowerment themes → Generates similar mood options: "Stories of triumph", "Characters who inspire courage" → Prioritizes films with empowerment, creativity, and underdog themes → Uses user's language style in future AI-generated options
