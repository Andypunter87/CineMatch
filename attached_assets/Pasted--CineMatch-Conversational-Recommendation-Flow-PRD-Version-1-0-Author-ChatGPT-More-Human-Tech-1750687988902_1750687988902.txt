🎬 CineMatch Conversational Recommendation Flow – PRD
Version: 1.0 Author: ChatGPT / More Human Technology Ltd Date: 2025-06-23

1. 🎯 Feature Overview
CineMatch will replace its static recommendation form with a warm, chat-style interface that collects user preferences in a conversational flow. The new flow is powered by OpenAI and styled as a conversation with a friendly, knowledgeable film buff — CineMate. The assistant gathers structured data to populate the existing recommendationRequestSchema, which is then used to fetch recommendations via the existing OpenAI prompt logic.

2. 🧩 Functional Requirements
2.1 Chat Experience
* Built from scratch using React (or similar) in Replit.
* Each step in the conversation presents:
    * A short question from CineMate
    * 3 button-based response options (mapped to schema enums)
    * An “Other” button that opens a free text input
* Responses update chat state and schema progressively.
* Final confirmation step before generating results.
2.2 Data Handling
* Output should be structured exactly as per recommendationRequestSchema.
* Chat state is stored in memory during session.
* Optional: Store full transcript in Firestore (userChats collection).
2.3 LLM Integration
* LLM guides the conversation and rephrases user free-text input.
* System prompt and turn-by-turn templates provided below.
* Final schema is not generated by the LLM — only user inputs are collected, then sent to OpenAI's recommender.

3. 🧠 LLM Design
3.1 System Prompt
text
CopyEdit
You are CineMate — a warm, smart, slightly nerdy film buff who helps people find the perfect movie based on how they feel and who they’re watching with. You're friendly and emotionally intuitive, never snobby.

Guide the user through a short conversation. At each step, ask one question. Offer three suggested responses and an “Other” option. If the user chooses “Other,” allow them to type freely and map it to the closest known option.

Keep it casual, upbeat, and rooted in mood, not genre.

3.2 Prompt Templates (Per Step)
Each question is sent with:
json
CopyEdit
{
  "step": "mood", // or "audience", "runtime", etc.
  "previousResponses": {...}, // optional
  "freeTextInput": null // populated only if user selects "Other"
}
And expected return:
json
CopyEdit
{
  "prompt": "What sort of vibe are you in the mood for?",
  "options": ["Make me laugh", "Get my heart racing", "Tug the heartstrings"],
  "schemaField": "mood",
  "mappedValues": ["laugh", "thrill", "cry"]
}

Friend Data

7. 🛠️ Implementation Notes for Replit Agent
* Use useState or similar to store schema-in-progress.
* Store recommendationRequestSchema locally until confirmed.
* Send structured schema to OpenAI recommender endpoint only after confirmation.
* Handle LLM completions using OpenAI’s chat endpoint (gpt-4-turbo or gpt-3.5-turbo-1106 is sufficient).
* Each response step can be pre-prompted using a static set of instructions, or handled in a single reusable LLM function.

8. 📊 Analytics & Future Enhancements
* Track drop-off per step to refine chat flow.
* Use common phrases from free-text to suggest new pre-written options.
* Optional: Post-recommendation feedback “Did this hit the mark?” for improving future recs.
